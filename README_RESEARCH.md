# Research Notes

This document expands on the scientific motivation behind Neural IK Lab engineered by Nabil K.

The multi-valued nature of inverse kinematics is treated explicitly: training
data are generated from a preferred branch so that the supervised mapping is
a function. Numerical solvers provide a third baseline that does not require
a closed form.

All quantitative claims in published materials derived from this repository
must be produced by executing the experiment suite; placeholders in the README
intentionally avoid fabricated numbers.
