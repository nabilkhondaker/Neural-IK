# Neural IK Lab

### Can a neural network learn inverse kinematics?

A research-oriented implementation of learned inverse kinematics for a 2R planar
robotic manipulator, with direct comparisons against analytical and numerical
solvers.

```
Target Position
      ↓
  Neural IK
      ↓
Joint Configuration
      ↓
Forward Kinematics
      ↓
Position Error
```

## Overview

**Neural IK Lab** investigates whether a feed-forward neural network can
approximate the inverse kinematics (IK) mapping for a two-link planar
manipulator, and how that approximation compares to classical analytical and
numerical methods in terms of accuracy, latency, robustness, and failure modes.

The project does **not** assume that neural IK is superior. It provides the
instrumentation to measure when it works, when it fails, and how it behaves
near singularities, workspace boundaries, and under noise.

## Research Question

> Can a neural network learn to approximate inverse kinematics for a robotic
> manipulator, and how does its performance compare with conventional analytical
> inverse kinematics?

Secondary questions:

- How does neural IK behave under input noise?
- Does accuracy degrade near kinematic singularities?
- How does performance scale with dataset size and model capacity?
- What is the inference latency relative to analytical / numerical solvers?

## Motivation

Classical IK is exact (when a closed form exists) but can be brittle at
singularities and requires branch selection for multi-valued solutions.
Numerical IK is general but iterative. Neural approximations offer constant-time
inference and potential robustness to noise, at the cost of approximation error
and data dependence. This repository is a controlled laboratory for quantifying
those trade-offs on a well-understood 2R system.

## Why Neural Inverse Kinematics?

- **Constant-time inference** after training
- **Differentiable** end-to-end with task losses
- Potential **noise robustness** when trained with augmentation
- A stepping stone toward learned whole-body inverse kinematics

Counterpoints: analytical solutions remain exact and faster for low-DOF arms;
neural models can silently fail outside the training distribution.

## Key Features

- Planar 2R robot with analytical FK / IK (elbow-up & elbow-down)
- Numerical IK: Jacobian transpose, pseudoinverse, damped least-squares
- Configurable MLP for neural IK
- Automated dataset generation from forward kinematics
- Train / val / test splits, normalization, validation checks
- Metrics: MAE, RMSE, percentiles (P50–P99), latency, throughput
- Experiment suite: baseline, noise, singularity, generalization, latency
- Visualization: robot pose, workspace, error heatmaps, training curves
- CLI (`neural-ik`), YAML configs, pytest suite, GitHub Actions workflows
- Research report generator

## Mathematical Background

### Forward Kinematics

\[
x = L_1 \cos\theta_1 + L_2 \cos(\theta_1+\theta_2)
\]
\[
y = L_1 \sin\theta_1 + L_2 \sin(\theta_1+\theta_2)
\]

### Analytical Inverse Kinematics

Using the law of cosines:

\[
\cos\theta_2 = \frac{x^2 + y^2 - L_1^2 - L_2^2}{2 L_1 L_2}
\]

Two real solutions exist when the target is reachable (elbow-up / elbow-down).
\(\theta_1\) is recovered via a two-argument arctangent of an adjusted vector.

### Numerical Inverse Kinematics

Iterative methods using the analytic Jacobian of the 2R arm:

- Jacobian transpose: \(\Delta\theta = \alpha J^\top e\)
- Pseudoinverse: \(\Delta\theta = \alpha J^{+} e\)
- Damped least-squares: \((JJ^\top + \lambda^2 I)\Delta x = e\)

### Neural Inverse Kinematics

A multilayer perceptron approximates \(f_\phi: (x,y) \mapsto (\theta_1,\theta_2)\).
Training targets are generated by sampling joints and applying FK, so the
network learns a particular branch of the multi-valued inverse.

### Workspace

\[
|L_1 - L_2| \le \sqrt{x^2+y^2} \le L_1 + L_2
\]

### Singularities

\(\det(J) \propto \sin\theta_2\). Fully stretched or folded postures are singular.

## Dataset Generation

```bash
python scripts/generate_dataset.py --samples 100000 --seed 42
# or
neural-ik generate-data --samples 100000 --seed 42
```

Samples are drawn in joint space, mapped through FK, optionally noised, then
split into train / val / test. Statistics (coverage, NaNs, duplicates) are
reported automatically.

## Model Architecture

Default MLP: `(x, y) → Linear → ReLU → … → (θ1, θ2)` with configurable width,
depth, activation, and dropout. Inputs and outputs are standardized using
training-set statistics.

## Training

```bash
python scripts/train.py --samples 20000 --epochs 30
# or
neural-ik train --config configs/default.yaml
```

Early stopping on validation loss. Best and last checkpoints are saved under
`artifacts/experiments/`.

## Evaluation

Predicted joints are passed through FK; Euclidean position error is the primary
metric. Analytical IK provides a near-zero-error baseline on reachable targets.

## Failure Cases

Evaluation scripts export the worst predictions for inspection. Typical failure
modes include:

- Targets near the workspace boundary
- Configurations near singularities (\(\theta_2 \approx 0\))
- Out-of-distribution noise levels
- Branch ambiguity when the model was trained on a single solution

## Limitations

- Restricted to a 2R planar arm
- Single-branch training (multi-head / mixture models are future work)
- No hardware-in-the-loop validation
- Numerical IK depends on initialization

## Python API

```python
from neural_ik.robotics.models.planar_2r import Planar2R
import numpy as np

robot = Planar2R(link_1=1.0, link_2=0.75)
theta, reachable = robot.analytical_ik(np.array([1.0, 0.5]), branch="elbow_up")
pos = robot.forward_kinematics(theta)
```
